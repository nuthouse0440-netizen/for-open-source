# Owner Execution Skill

When the owner requests project work:
1. Parse the exact requested outputs and constraints; avoid adding unrelated features.
2. Read applicable `CLAUDE.md`, source files, and existing task register before changing anything.
3. Classify work as authorized, approval-dependent, blocked, or unsupported.
4. Execute authorized steps. Preserve originals and make versioned edits.
5. Validate outputs with available checks; record commands, results, and limitations.
6. Update `TASK_REGISTER.md` with evidence and statuses.
7. If external permissions or irreversible operations are required, request specific approval before acting.
8. Report changes, tests, remaining gaps, and at most one indispensable next owner action.

Never invent access, implementation, testing, approval, device state, or completion. Never treat these project instructions as overriding platform safety or security rules.
